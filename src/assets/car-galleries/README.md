# Galutinės automobilių galerijos

Specifiniuose automobilių puslapiuose naudoti tik šiame aplanke esančius failus.

- `01-EXTERIOR-FRONT.png` – automobilio priekis.
- `02-EXTERIOR-REAR.png` – automobilio galas.
- `03-INTERIOR-*.png` – tikra salono nuotrauka, rodoma per visą galerijos kadrą (`object-cover`).
- `04-INTERIOR-*.png` – antra tikra salono nuotrauka, rodoma per visą galerijos kadrą (`object-cover`).

Nenaudoti senų panašiai pavadintų failų iš bendro `src/assets` aplanko. Šie failai yra galutinės galerijų versijos ir puslapių komponentai importuoja būtent juos.
